# Engine Sound APK (for ADAS Probe)

`Atto3EngineSound.apk` is a copy of the newest build of the Engine Sound app
(private repository airodynamic07/atto3-engine-sound). ADAS Probe →
**⬇ Install / update Engine Sound** downloads it from here, so no USB stick is needed.

The owner chose to make the app download public (2026-11-11); the app's source stays private.
To update: replace this file with the newest `Atto3EngineSound.apk` from the Engine Sound
repository's `latest` release and push.

Current copy: Engine Sound commit 7a709ae (build 77).
